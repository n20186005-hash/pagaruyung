# Rancangan Satu Halaman

| Kebutuhan asli | Implementasi |
| --- | --- |
| Bahasa setempat, bukan multibahasa | Seluruh antarmuka, navigasi, konten, FAQ, kebijakan dan metadata menggunakan Bahasa Indonesia. |
| Gaya mengikuti karakter tempat | Identitas visual mengambil inspirasi dari atap gonjong Rumah Gadang, ukiran Minangkabau, warna kayu surian, emas, dan hijau lanskap dataran tinggi. |
| Foto nyata dan lokal | Empat foto Istano Basa Pagaruyung disimpan di `public/images`; kredit CC BY-SA dicantumkan di halaman. |
| Sejarah dan budaya | Bagian pengantar, kronologi, Rajo Tigo Selo, rumah gadang, dan catatan untuk menghormati ruang budaya. |
| Informasi kunjungan | Jam, durasi, biaya sebagai kisaran/konfirmasi di lokasi, tata cara berkunjung, parkir, toilet, makan, penginapan, belanja, dan pengisian bahan bakar. |
| Transportasi rinci | Jalur dari bandara, bus/angkot ke Batusangkar, serta taksi/ojek atau kendaraan sewaan untuk tahap akhir. |
| Kuliner dan tujuan sekitar | Rekomendasi berdasarkan kategori yang netral serta daftar konteks wilayah tanpa menyebut pedagang tertentu. |
| Peta dan SEO | Embed Google Maps berbahasa Indonesia, TouristAttraction JSON-LD, FAQPage JSON-LD, canonical/OG bersyarat, dan sitemap bersyarat pada satu konfigurasi `site`. |
| Privasi, syarat, cookie | Tiga dialog aksesibel dari footer; preferensi cookie tersimpan secara lokal dan skrip GA4 hanya dimuat setelah persetujuan analitik. |
| Teknis dan pengiriman | Astro, Tailwind, TypeScript, pnpm versi tetap, Cloudflare Worker Static Assets, berkas `.node-version`, tidak ada CMS/login/database, dan arsip ZIP proyek. |
